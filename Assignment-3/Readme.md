############################################

Description
This Python script provides a robust way to calculate the factorial of a given number using loop-based approach

Function-Based: Uses a dedicated factorial() function for better code organization.

Iterative Logic: Calculates the result using a for loop.

User Interaction: Accepts input directly from the console.

How to Run
Ensure you have Python installed.

Run the script:Assignment3-task1.py

Example Output 
Enter a number: 5
Factorial of 5 is 120

Description
This script demonstrates the practical application of Python's built-in math module. It performs complex mathematical computations—square roots, natural logarithms, and sine of number.

math.sqrt(x): Computes the square root.
