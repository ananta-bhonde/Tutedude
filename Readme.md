Assignment – Basic Control Flow and Loops
Overview

This repository contains two beginner-level Python programs designed to demonstrate the use of conditional statements and loops. These tasks help in understanding basic logic building in Python.

Task 1: Check if a Number is Even or Odd
🔹 Problem Statement

Write a Python program that:

Takes an integer input from the user.

Checks whether the number is even or odd using an if-else statement.

Displays the result accordingly.

🔹 Logic Used

An integer is even if it is divisible by 2.

Otherwise, it is odd.

The modulus operator (%) is used to perform this check.

Task 2: Sum of Integers from 1 to 50 Using a Loop
🔹 Problem Statement

Write a Python program that:

Uses a for loop to iterate over numbers from 1 to 50.

Calculates the sum of all integers in this range.

Displays the final sum.

🔹 Logic Used

Initialize a variable to store the sum.

Use a for loop to iterate from 1 to 50.

Add each number to the sum variable.

Print the final result.
